# DevFoundry Web Console - Quick Start Guide

## Run the Application

```bash
cd packages/web-console
npm install
npm run dev
```

Then open: **http://localhost:3001**

## Default Login

- Email: `admin@devfoundry.local`
- Password: `devfoundry`

## What's Included

✅ Login/Authentication  
✅ Dashboard with overview stats  
✅ Tasks page (all phases: Submitted, Qualified, Running, Validating, AwaitingReview, Completed, Failed, Cancelled, Paused)  
✅ Task details with evidence review  
✅ Project configuration (repos, tools, skills, context status)  
✅ Appliance health (CPU/RAM/GPU, services, hardware)  

## Tech Stack

React 18 + TypeScript + Tailwind CSS + Vite + Axios

## Requirements

- Node.js 18+
- PostgreSQL running
- DevFoundry API on port 3000
